01 · 그로스 진단 템플릿Python · Claude API

지금 브랜드가 어디서 막혀 있는지 진단하고, 다음에 풀어야 할 과제를 단계별로 안내합니다

광고·매출·GA4 원본을 넣으면 퍼널 단계마다 현재 상태를 판정하고, 데이터를 근거로 해결해야 할 과제를 우선순위와 단계별 실행 순서로 정리해 줍니다. 고객사가 받는 첫 장에는 지금 상태 한 문장, 핵심 숫자, 할 일 3개(누가·언제까지·어떤 숫자를 얼마로)만 담습니다.

자세히
  • 퍼널 5단계, 지표 정의서, 판정 규칙 11개로 진단 기준을 고정. 고객사마다 바뀌는 값은 설정 파일 하나에 모음
  • 지표 계산 → 측정 점검 → 현황 진단 → 과제 도출 → 진단 문서 5종 → 자동 검수를 한 번에 실행
  • 계산과 검수는 코드로 고정하고, 해석과 문장은 AI가 맡게 나눠 누가 돌려도 같은 숫자가 나오게 함
  • 실데이터 검증 중 하루치 광고비 누락(4.3%) 같은 데이터 문제를 찾으면, 다음부터 자동으로 잡히는 점검 규칙으로 추가
